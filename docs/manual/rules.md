# 规则引擎

规则引擎对点位数据流做实时计算，满足判定条件时触发联动动作（反控设备或记录日志），是平台实现"无人值守"能力核心。

![规则引擎](/images/rules.png)

## 查询规则

| 条件 | 说明 |
| :--- | :--- |
| 关键字 | 按规则 ID、名称、监控点位或联动指令模糊搜索 |
| 监控设备 | 按规则绑定的设备过滤 |
| 启停状态 | 已启用 / 已停用 |

## 创建规则

### 基本信息

| 字段 | 说明 |
| :--- | :--- |
| 规则 ID | 唯一标识（如 `RULE_101`） |
| 规则名称 | 建议写清场景，如"1 号离心风机轴承超温自动风扇与降速联动" |
| 监控对象设备 | 选择被监控的设备 |
| 监控点位 / 物模型事件 | 选择该设备物模型下的属性点位或事件 |

### 判定逻辑

| 字段 | 说明 |
| :--- | :--- |
| 判定逻辑类型 | 三选一：**单点阈值比较**、**区间内触发**、**超范围/越界触发** |
| 判断运算符 | 单点阈值时使用：`>`、`>=`、`<`、`<=`、`==`、`!=` |
| 判定阈值 | 单点阈值的目标值 |
| 区间下限 / 上限 | 区间类型时使用，如 `20.0 <= 点位 <= 80.0` |

### 触发条件模式

控制判定的触发时机，配合点位的采样模式使用：周期采样（PERIODIC）的点位按采集节拍判定，变化上报（COV）的点位在值变化时判定。

## 联动动作

每条规则可挂接多个动作，每个动作可独立开关：

| 字段 | 说明 |
| :--- | :--- |
| 动作类型 | `SERVICE` 反向控制 / `LOG` 记录日志 |
| 联动动作名称 | 便于识别（如"自动启动散热风机"） |
| 详细配置 / 指令内容 | `SERVICE` 类型填写目标点位/服务与目标值；`LOG` 类型填写记录文案 |

典型组合：超温场景配置两个动作 —— `SERVICE` 启动散热风机 + `LOG` 记录超温事件。即使不配反控，规则命中也会进入[告警中心](./alarms.md)形成事件流水。

## 启停与调试

- 规则默认创建后可先**停用**，验证点位数据正常后再启用；
- 联动到 `SERVICE` 的规则建议先在[数据监控](./data.md)确认点位品质正常，避免误触发；
- 规则命中后，反控执行流水在[日志审计](./logs.md)中可查。

## 配置示例

**轴承超温降速联动**

| 配置项 | 值 |
| :--- | :--- |
| 监控点位 | `BearingTemp` 轴承温度（RW） |
| 判定逻辑 | 单点阈值比较，`>` `80.0` ℃ |
| 动作 1 | SERVICE：下发风机启动指令 |
| 动作 2 | SERVICE：下发降频至 30Hz |
| 动作 3 | LOG：记录"轴承温度超 80℃" |

**压力区间保运**

| 配置项 | 值 |
| :--- | :--- |
| 监控点位 | `TankPress` 储罐压力 |
| 判定逻辑 | 超范围/越界触发，`< 0.2` 或 `> 0.8` MPa |
| 动作 | LOG：记录压力越界与实时值快照 |
