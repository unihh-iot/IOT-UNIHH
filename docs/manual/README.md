# 操作手册

本手册介绍 UNIHH-IOT 平台各功能页面的使用方式，面向现场工程师、系统集成商与运维人员。

## 登录平台

浏览器访问前端地址（本地开发环境为 `http://localhost:5173`），输入账号密码登录。默认超级管理员账号：`admin` / `unihhiot`。

![系统登录](/images/login.png)

登录凭据以 Token 形式保存在浏览器本地，过期或失效时自动跳回登录页。忘记密码请联系管理员在【系统管理 → 用户管理】中重置。

::: warning
生产环境部署后请第一时间修改默认密码，并为操作人员分配独立账号与角色。
:::

## 主界面布局

登录后进入监控大盘。左侧为导航菜单，顶部为当前用户与退出入口，菜单按角色权限动态加载。

## 推荐的上手路径

第一次使用平台，建议按以下顺序操作，完整走通"建模 → 接设备 → 采数据 → 配告警"链路：

1. [创建物模型](./thingmodels.md)：定义一类设备的属性、服务与事件；
2. [接入驱动](./drivers.md)：确认对应协议驱动已启动并在线；
3. [创建设备](./devices.md)：绑定物模型与驱动，配置连接参数与点位映射；
4. [查看实时数据](./data.md)：确认采集正常、品质为正常；
5. [配置规则](./rules.md)：为关键点位设置阈值联动；
6. [处理告警](./alarms.md)：模拟越限，验证告警链路。
