# 设备管理

设备管理维护现场物理设备的台账、连接参数、点位绑定与数采运行状态，同时是反向控制的操作入口。

![设备管理](/images/devices.png)

## 查询设备

顶部筛选条件：

| 条件 | 说明 |
| :--- | :--- |
| 设备 ID / 名称 | 模糊搜索 |
| 绑定驱动 | 按协议驱动过滤 |
| 物模型模板 | 按绑定的物模型过滤 |
| 数采状态 | 数采运行中 / 已暂停数采 |

## 新建设备

点击**新增设备**，表单字段：

| 字段 | 说明 |
| :--- | :--- |
| 设备唯一 ID | 全局唯一标识，建议沿用现场编号（如 `PLC01`） |
| 设备显示名称 | 列表与告警中展示的名称 |
| 绑定物模型模板 | 决定该设备可用的属性、服务与事件 |
| 通信协议驱动 | 选择与设备协议一致的驱动 |
| 基础数采周期 | 轮询采集的基础间隔（毫秒），按现场总线负载能力设置 |
| 驱动连接参数 | 表单由所选驱动的参数 Schema 动态生成（如 Modbus 的 IP、端口、从站号；S7 的机架/槽号） |

保存后，平台将设备配置经 MQTT 定向下发至对应驱动，驱动随即开始采集。

## 点位绑定

物模型定义的是"逻辑点位"（如 `MotorTemp` 电机温度），设备绑定时要把它映射到"物理地址"（如 Modbus 的 `40001`）。在设备详情中逐个配置：

| 字段 | 说明 |
| :--- | :--- |
| 逻辑点位 Code | 来自物模型的属性定义 |
| 点位名称 | 便于现场人员识别的名称 |
| 数据类型 | FLOAT / DOUBLE / INT / INT32 / INT64 / BOOL / STRING / ENUM |
| 读写 | 只读（R）或读写（RW），RW 点位才允许反控 |
| 物理寄存器地址 | 按协议语义填写，如 Modbus `40001`、S7 `DB1.DBW0`、OPC UA `ns=2;s=Temp` |
| 缩放系数（Scale） | 工程值 = 原始值 × Scale + Offset |
| 零点偏置（Offset） | 与缩放系数配合完成量程换算 |

::: tip
缩放与偏置在平台侧统一换算，驱动只需上送原始值。例如量程 0~100℃ 对应寄存器值 0~32760 时，Scale 填 `0.003052`，Offset 填 `0`。
:::

## 数采启停

每台设备可单独启停数采：

- **运行中**：驱动按数采周期轮询点位并上报数据；
- **已暂停**：保留台账与配置，暂停轮询，适合设备检修或临时停机场景。

## 反向控制

对配置了 RW 点位或控制服务的设备，可在设备详情中直接下发控制指令：

![设备反控](/images/devices.png)

### 按点位反写

1. 选择**目标控制点位**（下拉中仅列出物模型里读写模式为 RW 的属性）；
2. 输入目标值，确认下发。

指令经 `网关 → 管理中心 → EMQX（iot/driver/{code}/cmd）→ 驱动` 链路到达设备。驱动在通道锁内排队执行寄存器写入，与采集轮询互不干扰。

### 按服务调用

若物模型定义了控制服务（Service），可选择**控制服务**并填写入参下发，适合"启动/停止/复位"这类组合动作。

### 查看执行结果

反控指令的执行流水（参数快照、耗时、成败）可在[日志审计](./logs.md) → 设备反控服务下发日志中查看。

## 生命周期状态联动

- 驱动离线时，其下挂设备自动级联置为离线；
- 设备物理链路断连或恢复时，驱动通过 `iot/device/status` 主题通知平台更新状态。

## 常见问题

**设备创建后一直没有数据？**

1. 设备详情确认数采状态为运行中；
2. 确认对应驱动在线（见[驱动管理](./drivers.md)）；
3. 检查连接参数（IP、端口、从站号/槽号）是否与现场一致；
4. 到[数据监控](./data.md)页查看点位品质，品质为异常（Quality=0）说明链路通但读数失败，重点核对物理寄存器地址。

**反写指令下发失败？**

1. 确认点位读写模式为 RW；
2. 确认设备在线且数采正常（同一通道能读通才能写）；
3. 查看反控日志中的失败原因与耗时；
4. RS485 总线场景下确认总线上无地址冲突、终端电阻正常。
