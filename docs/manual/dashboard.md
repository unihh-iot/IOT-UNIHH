# 监控大盘

监控大盘是平台的全局态势页，登录后默认进入。页面自上而下分为统计卡片与图表两个区域，数据由网关转发至管理中心 Dashboard 接口实时获取。

![监控大盘](/images/dashboard.png)

## 统计卡片

| 卡片 | 含义 |
| :--- | :--- |
| 挂载协议驱动数 | 已注册的协议驱动总数与在线数 |
| 接入数采设备总数 | 平台台账中的设备总数 |
| 物模型定义标准 | 已创建的物模型模板数量 |
| 规则引擎联动链路 | 已配置的规则数量 |
| 数据吞吐采集总量 | 累计采集记录数与平均响应耗时 |
| 待处理告警事件 | 未处理状态的告警事件数 |

卡片数字异常时的排查入口：

- 驱动在线数为 0 → 进入[驱动管理](./drivers.md)执行通道心跳自检；
- 设备数为 0 → 确认是否已在[设备管理](./devices.md)中创建设备；
- 待处理告警持续增长 → 进入[告警中心](./alarms.md)确认与处置。

## 图表

- **接入设备通信协议分布**：按驱动类型统计设备占比，用于核对各协议的接入规模；
- **告警事件等级分布统计**：按 CRITICAL / HIGH / WARN / INFO 四级统计告警分布，用于评估现场健康度。

## 使用建议

- 大盘适合投屏到车间看板，作为每日巡检的第一入口；
- 平均响应耗时持续升高通常意味着 EMQX 或存储引擎压力增大，建议结合[部署与运维](../guide/deploy.md)检查对应组件。
