# 物模型管理

物模型是设备的标准化抽象，将一类设备的采集、控制与告警能力定义为统一的模板。设备通过绑定物模型获得标准化的数据结构，上层应用无需关心底层协议差异。

![物模型管理](/images/thingmodels.png)

## 模板查询

支持按**模板编码 / 名称**模糊搜索，并按工业分类筛选。内置分类：

- 旋转机械/变频电机
- PLC 控制器/自动化
- 工业以太网网关
- 环境与能源监测

## 创建物模型

点击**新增物模型**，填写：

| 字段 | 说明 |
| :--- | :--- |
| 物模型编码（ID） | 模板唯一标识，建议使用业务语义编码（如 `centrifugal-fan`） |
| 物模型名称 | 模板显示名称 |
| 工业分类 | 归类便于检索 |
| 模板功能描述 | 说明该模板适用的设备类型 |

## 三要素定义

一个物模型由属性、服务、事件三部分构成，在编辑页中分区维护。

### 属性点位定义（Properties）

属性描述设备可采集的状态量，是数采的基本单元：

| 字段 | 说明 |
| :--- | :--- |
| 点位 Code | 属性唯一标识，采集与存储均以此为准（如 `MotorTemp`） |
| 点位名称 | 显示名称（如"电机绕组温度"） |
| 数据类型 | FLOAT / DOUBLE / INT / STRING / BOOL / ENUM |
| 枚举映射 | 数据类型为 ENUM 时定义键值映射（如 `1: 运行, 0: 停机`） |
| 读写模式 | R（只读）/ RW（可读可写，仅 RW 属性可被反向控制） |
| 采样触发模式 | `PERIODIC` 按设备数采周期采样 / `COV` 值变化时上报 |
| 物理单位 | 如 ℃、MPa、kW，展示与告警时使用 |
| 功能描述 | 详细说明 |

### 控制服务定义（Services）

服务描述设备可执行的组合动作（如"远程启动""降频至 30Hz"）：

| 字段 | 说明 |
| :--- | :--- |
| 服务 Code | 服务唯一标识 |
| 服务名称 | 显示名称 |
| 入参定义 | 调用该服务所需的参数列表（名称、类型、默认值） |

服务调用入口在[设备管理](./devices.md)的反控面板中。

### 告警事件定义（Events）

事件描述设备可能触发的异常或状态上报：

| 字段 | 说明 |
| :--- | :--- |
| 事件 Code | 事件唯一标识 |
| 事件名称 | 显示名称 |
| 事件类型 | 故障 / 告警 / 信息等 |
| 告警级别 | 定义该事件的默认严重程度 |
| 事件能力描述 | 事件 Payload 结构与触发条件说明 |

## 与设备、规则的关系

```
物模型（模板） ──绑定──> 设备（实例） ──点位映射──> 物理寄存器
     │                                      │
     └── 属性/事件 ──> 规则引擎监控对象 <────┘
```

- 同一物模型可被多台设备复用，一处修改、处处生效；
- [规则引擎](./rules.md)的监控对象直接引用物模型的属性点位与事件；
- 平台已内置常用模板，可直接复制修改。

## 建模建议

- 属性粒度与现场仪表测点对齐，一个测点一个属性，便于追溯；
- 会参与联动控制的状态量，读写模式定义为 RW；纯监测量一律 R，避免误操作；
- 数值量大、变化平缓的点位选 `COV` 模式可显著降低总线与存储压力。
