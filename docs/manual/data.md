# 数据监控

数据监控页用于查看单台设备所有点位的实时采集值、数据品质与采集时间，是现场调试和验收的常用工具。

![实时数采监控](/images/data.png)

## 选择设备

页面顶部**选择目标设备**下拉列出全部台账设备（格式为 `设备名称 (设备ID)`）。下方提供**快捷选择常用设备**入口，方便在调试时快速切换。

选中设备后，信息条展示当前设备的整体状态：

| 字段 | 含义 |
| :--- | :--- |
| 当前设备 | 设备名称与 ID |
| 物模型模板 | 该设备绑定的模型 |
| 协议驱动 | 承接采集的驱动 |
| 网络通道 | 设备连接通道标识 |
| 数采状态 | 运行中 / 已暂停 |
| 设备基频周期 | 该设备配置的数采周期 |
| 点位数 | 当前模型下绑定的点位总数 |

## 筛选点位

| 条件 | 说明 |
| :--- | :--- |
| 点位查找 | 按点位 Code / 名称 / 物理地址模糊搜索 |
| 数据类型 | FLOAT / DOUBLE / INT / BOOL / STRING / ENUM |
| 读写权限 | 只读（R）/ 读写（RW） |
| 质量状态 | 正常（Quality=1）/ 异常（Quality=0） |

点击**重置**恢复默认筛选。

## 读懂数据品质（Quality）

每个点位值都带有品质标记：

| 品质 | 含义 | 排查建议 |
| :--- | :--- | :--- |
| Quality = 1（正常） | 驱动成功读取且解析通过 | — |
| Quality = 0（异常） | 本次读取失败或解析失败 | 核对物理寄存器地址、数据类型与字节序；检查设备是否掉线 |

::: warning
品质为异常的点位值不应参与联动判断与统计。平台规则引擎在计算时会校验品质，异常值不会触发误告警。
:::

## 调试技巧

- **新建点位后先看品质再看数值**：品质正常说明链路与地址配置正确，数值不对通常是 Scale/Offset 或字节序问题；
- **对比基频周期**：若刷新间隔明显大于设备数采周期，优先检查 EMQX 与驱动的 CPU/网络负载；
- **配合驱动自检**：数值长时间不更新时，到[驱动管理](./drivers.md)执行通道心跳自检，确认驱动与链路状态。
