# 系统管理

系统管理提供平台的 RBAC 权限体系与基础数据配置，包括用户、角色、菜单与字典四个模块。

## 用户管理

维护平台登录账号。

![用户管理](/images/user.png)

### 查询用户

| 条件 | 说明 |
| :--- | :--- |
| 关键字 | 按用户名 / 姓名 / 手机号模糊搜索 |
| 账号状态 | 正常启用 / 冻结停用 |

### 新增用户

| 字段 | 说明 |
| :--- | :--- |
| 登录账号 | 字母/数字组合，全局唯一 |
| 用户姓名 | 显示名称 |
| 分配角色 | 决定该用户可见的菜单与可执行的操作 |
| 联系手机 / 电子邮箱 | 联系方式 |
| 状态 | 停用后该账号立即无法登录 |
| 备注 | 选填 |

列表中还可查看每个账号的**最后登录时间**，长期未登录的账号建议回收。

::: warning
不要多人共用 `admin` 账号。为每位操作人员建立独立账号并分配最小必要角色，操作才可追溯到人。
:::

## 角色权限

角色是权限的载体，通过为角色勾选菜单/功能权限，实现按岗位授权。

![角色管理](/images/roles.png)

典型角色规划：

| 角色 | 权限范围 | 适用岗位 |
| :--- | :--- | :--- |
| 超级管理员 | 全部功能 | 平台负责人（仅 1~2 人） |
| 运维工程师 | 驱动、设备、数据、告警、日志 | 现场运维 |
| 工艺/值班人员 | 大盘、数据监控、告警处置 | 中控值班 |
| 只读观察者 | 大盘、数据监控 | 管理层查看 |

## 菜单路由

维护左侧导航的菜单树。菜单项绑定前端路由组件，角色被授权后菜单动态加载。

![菜单管理](/images/menus.png)

说明：

- 新增页面组件时需在此登记路由（组件路径对应 `src/views` 下的 `.vue` 文件）；
- 调整菜单层级或显隐后，刷新页面即可生效；
- 建议不要随意停用系统内置菜单，以免影响功能完整性。

## 字典管理

维护平台中可枚举的下拉数据（如告警级别、事件类型、工业分类等），业务页面据此渲染选项。

![字典管理](/images/dicts.png)

说明：

- 字典按类型分组，每类下维护多个键值项；
- 修改字典项仅影响后续新增数据的展示，历史数据保持原值；
- 新增自定义业务枚举时优先使用字典，避免硬编码。
