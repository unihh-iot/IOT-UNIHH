# 系统架构

## 整体架构

```text
+-----------------------------------------------------------------------------------+
|                            物理设备与现场工业总线 (物理层)                        |
|       Modbus PLC/仪表  |  西门子 S7-200/300/1200/1500  |  OPC UA Server / SCADA   |
+----------------------------------------+------------------------------------------+
                                         | 物理网络 (TCP/IP / 串口 RS485)
                                         v
+-----------------------------------------------------------------------------------+
|                        分布式独立协议驱动服务 (南向驱动层)                        |
|   [Modbus 驱动 :28011]   |   [西门子 S7 驱动 :28012]   |   [OPC UA 驱动 :28013]   |
|   继承 AbstractDriverPlugin 基类，由 BaseDriverMqttManager 自动托管 MQTT 总线通信 |
+----------------------------------------+------------------------------------------+
                                         | EMQX MQTT 总线 (数据上报 / 心跳 / 遗嘱 / 反控)
                                         v
+-----------------------------------------------------------------------------------+
|                           核心工业消息总线 (消息层)                               |
|                  EMQX Broker 集群  <=======>  Redis 缓存 / 在线状态               |
+----------------------------------------+------------------------------------------+
                                         | 共享订阅 / 专属主题广播
                                         v
+-----------------------------------------------------------------------------------+
|                         核心业务微服务群 (应用与平台层)                           |
|  [统一网关 unihh-gateway :28000]                                                  |
|       |-- REST/JWT 路由与鉴权 --> [管理中心 unihh-admin :28001] (物模型/设备/驱动管理) |
|       `-- REST/数据流转发 ------> [数据中心 unihh-data :28002] (规则引擎/数据入库) |
+----------------------------------------+------------------------------------------+
                                         | 策略路由 (StorageEngineRouter)
                                         v
+-----------------------------------------------------------------------------------+
|                             多形式持久化存储 (存储层)                             |
|    TDengine (时序)  |  TimescaleDB / InfluxDB  |  MySQL 8.0 (业务)  |  Redis 缓存 |
+-----------------------------------------------------------------------------------+
```

## 服务拆分

### 独立微服务进程

| 模块名称 | 进程类型 | 默认端口 | 核心职责 |
| :--- | :--- | :--- | :--- |
| `unihh-gateway` | 微服务 | 28000 | 统一访问入口、REST 路由分发、CORS 处理、JWT 鉴权拦截 |
| `unihh-admin` | 微服务 | 28001 | 用户角色 RBAC、设备台账、物模型定义、驱动生命周期托管、控制指令下发 |
| `unihh-data` | 微服务 | 28002 | 点位清洗归一化、规则引擎运算、告警触发、存储引擎持久化分流 |
| `unihh-driver-modbus` | 驱动服务 | 28011 | Modbus TCP/RTU 采集与寄存器反写 |
| `unihh-driver-s7` | 驱动服务 | 28012 | 西门子 S7-200 SMART/300/1200/1500，DB 块及各存储区读写 |
| `unihh-driver-opcua` | 驱动服务 | 28013 | OPC UA NodeId 节点采集与方法调用 |

### 共享 Maven SDK 模块

| 模块名称 | 核心职责 |
| :--- | :--- |
| `unihh-common` | 全局通用模型（`PointData`、`DriverInfo`、`DeviceConfig`）、统一响应体、EMQX MQTT 客户端底座 |
| `unihh-protocol` | 驱动基类 `AbstractDriverPlugin`、采集轮询引擎 `DriverPollingEngine`、端点控制器 `BaseDriverController`、工业大小端工具 `IndustrialEndianUtils` |
| `unihh-storage` | 策略存储接口 `DataStorageEngine`、路由适配器 `StorageEngineRouter`，内置 Memory/Redis/MySQL/TDengine 实现 |

## 核心数据流

### 驱动生命周期与遗嘱保活

```text
[驱动服务启动]            [EMQX Broker]                 [管理中心 unihh-admin]
      |                        |                                   |
      |-- 1. setWill(LWT) ---->| (注册掉线遗嘱, retained=true)     |
      |-- 2. connect() ------->|                                   |
      |-- 3. publish(ONLINE) ->|---------------------------------->| (同步驱动在线状态)
      |-- 4. register -------->|-- iot/driver/register ----------->| (写入驱动注册信息)
      |                        |                                   |-- 下发已配置设备与点位
      |<-- config/update ------|<-- iot/driver/{code}/device/config|
      |                        |                                   |
      | [每 5s 定时心跳]        |                                   |
      |-- 5. heartbeat ------->|-- iot/driver/heartbeat ---------->| (刷新看门狗时间戳)
      |                        |                                   |
   [异常断电/崩溃]             |                                   |
      x                        |-- 6. Broker 广播 LWT 遗嘱 -------->| (置为离线)
                               |   (iot/driver/{code}/status)      |-- 级联下挂设备离线
                               |                                   |
                               |                                   | [Watchdog 巡检]
                               |                                   | (心跳超 15s 无响应置离线)
```

要点：

- 驱动正常下线或异常崩溃，管理中心都能在秒级感知；
- 看门狗在 MQTT 遗嘱之外提供第二重保障：心跳超过 15 秒未更新即判定离线；
- 驱动离线会级联将其下挂设备标记为离线，避免虚假在线状态。

### 采集与存储分流

```text
[物理设备] --> [驱动 PollingEngine] --> [EMQX iot/driver/+/data] --> [数据中心 unihh-data] --> [StorageEngineRouter]
 (PLC/仪表)      点位解析/工程值换算         共享订阅消费               规则计算/告警判定            +-- TDengine (时序)
                 品质(Quality)标记                                   清洗校准                      +-- MySQL (持久化)
                                                                                                    `-- Redis (实时快照)
```

### 反向控制链路

```text
[前端/业务方] --> [网关 :28000] --> [管理中心 :28001] --> [EMQX iot/driver/{code}/cmd] --> [驱动服务] --> [物理设备]
  点位反写请求      路由与鉴权         构建控制指令             专属主题定向              getChannelLock 排队   寄存器改写
                                                                              writePoint(...)
```

半双工总线（如 RS485）上的读写在通道锁内自动排队串行执行，详见[驱动管理操作说明](../manual/drivers.md)。

## MQTT 主题规范

平台所有驱动交互均基于 MQTT 主题，完整主题表见 [MQTT 主题参考](../reference/mqtt-topics.md)。
